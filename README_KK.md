# Кәсіби практиканы басқару жобасының жұмыс нұсқасы

Тақырып: Кәсіби практика жетекшісінің автоматтандырылған жұмыс орны.
Пән: Ақпараттық жүйелердің қолданбалы бағдарламалық жасақтамасы.
Нұсқа: негізгі мүмкіндіктері іске асқан оқу прототипі. Әрі қарай дамытуға арналған.

## 1–6 зертханаларға арналған FastAPI нұсқасы

Жобада бастапқы жергілікті Python нұсқасы (app.py) сақталған. Зертханалардағы стекпен жұмыс істеу үшін соған қосымша FastAPI + SQLModel API және Streamlit интерфейсі жасалды. Екі нұсқа да кәсіби практиканы басқару тақырыбын және schema.sql деректер құрылымын қолданады. Бастапқы нұсқа 8765 портында, зертханалық нұсқа 8000 және 8501 порттарында іске қосылады. Бір дерекқорды қатар өзгертпеу үшін екі режимді бір уақытта ашпаған дұрыс.

ER диаграммасы: `docs/ER_DIAGRAM.md`.

Жергілікті іске қосу (Python 3.10+):

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 -m course_backend.seed
uvicorn course_backend.main:app --reload
```

Екінші терминалда интерфейсті ашыңыз:

```bash
source .venv/bin/activate
streamlit run course_frontend/ui.py
```

Интерфейс: http://localhost:8501 · API құжаттамасы: http://127.0.0.1:8000/docs

API-де практика тізімін/жеке жазбаны оқу, жазба қосу, ішінара өзгерту және жою бар. Іздеу студенттің аты, тобы және практика базасы бойынша жүреді; практика түрі мен мерзімге де сүзуге болады. Келісімшарт мерзімі, студенттің қатар келген практикасы және базаның сыйымдылығы тексеріледі.

Docker Desktop арқылы екі қызметті бірге іске қосу:

```bash
docker compose up --build
```

Streamlit: http://localhost:8501 · Swagger UI: http://localhost:8000/docs. SQLite деректері `praktika_data` Docker volume ішінде сақталады. Тоқтату: `docker compose down` (volume қалады). Деректерімен бірге жою: `docker compose down -v`.

## Іске қосу

Python 3.10 немесе одан жаңасы керек. Қосымша Python пакеттері қажет емес.

1. Архивті жеке бумаға ашыңыз.
2. Терминалда сол бумаға кіріңіз.
3. `python3 app.py` командасын орындаңыз. Windows жүйесінде `py -3 app.py`.
4. Браузерде http://127.0.0.1:8765 мекенжайын ашыңыз.

macOS: start.command; Windows: start.bat файлдары іске қосу командаларын қамтиды.
Егер файлды екі рет басу жұмыс істемесе, терминал командасын қолданыңыз.
Серверді тоқтату: Ctrl+C. Қайта қосқанда деректер сақталады.
Басқа порт: `PORT=8888 python3 app.py` (macOS/Linux).

## Дайын мүмкіндіктер

- Толық жаңартылған қазақша интерфейс, ашық және қараңғы режим ауыстырғышы; режим браузерде сақталады.
- Студенттер, ұйымдар, жетекшілер және келісімшарттар: қосу, қарау, өзгерту, жою.
- «Құжат үлгілері» бөлімінде практика туралы анықтама, студент күнделігі және оқу орны мен практика базасы арасындағы жалпы шарт бланкілері; браузерден басып шығару/PDF.
- Практикаға бөлу: келісім мерзімі, орын саны, қатар келетін практикаларды тексеру.
- Мәтіндік күнделік пен есеп; жетекшінің пікірі және тексеру мәртебесі.
- Бағалау және қорытынды баллды есептеу: 10% + 20% + 40% + 30%.
- Іздеу, статистика, CSV ведомость, браузер арқылы басып шығару.
- SQLite сақтау, үш рөл, PBKDF2 құпиясөз хэші, CSRF токені, аудит кестесі.
- Кілтсіз анықтамалық және API қосылғанда қазақша ЖИ көмекшісі.

## ЖИ көмекшісін қосу

Кілтсіз нұсқа — ережелерге негізделген анықтамалық. Ол тілдік модель емес.
Нақты модель үшін жеке OpenAI API кілті мен сол модельге қолжетімділік қажет.
Кілтті чатқа, кодқа немесе браузерге енгізбеңіз. Оны сервердің орта айнымалысына орнатыңыз:

macOS/Linux терминалының zsh ортасында кілтті экранға шығармай енгізу:

```zsh
read -s 'OPENAI_API_KEY?API кілті: '
export OPENAI_API_KEY
export OPENAI_MODEL='gpt-5.5'
python3 app.py
```

Windows PowerShell: OPENAI_API_KEY және OPENAI_MODEL айнымалыларын жергілікті ортада орнатыңыз, кейін `py -3 app.py` орындаңыз. Модель атауын аккаунтыңызда қолжетімді модельге ауыстыруға болады.

Көмекші сұрақты және тек жиынтық сандарды Responses API-ге жібереді; студенттердің аты-жөні мен есептері автоматты жіберілмейді. Сұраққа жеке дерек жазбаңыз. Модель тек кеңес береді, базаны өзгертпейді. Қосылу қатесі болса, офлайн жауапқа өтеді және ол белгіленеді. API кілтсіз болғандықтан, нақты модельмен онлайн жауап бұл жинақта тексерілмеген.
Ресми нұсқаулық: https://developers.openai.com/api/docs/quickstart

## Код қайда орналасқан

- app.py — HTTP сервер, сессиялар, рөлдер, валидация, CRUD және CSV.
- schema.sql — кестелер, сыртқы кілттер, шектеулер.
- assistant.py — ЖИ сұрауы мен офлайн анықтамалық.
- dist/index.html — бет қаңқасы.
- dist/style.css — дизайн және мобильді көрініс.
- dist/app.js — навигация, формалар, кестелер, чат.
- dist/seed.json — бастапқы оқу деректері.
- test_app.py — оқшауланған базаға арналған интеграциялық тексерулер.
- NEXT_STEPS_KK.md — келесі апталарға тапсырмалар.

data/praktika.sqlite3 бірінші іске қосқанда автоматты жасалады. Резервтік көшірме алу алдында серверді тоқтатып, осы файлды көшіріңіз. data/ бумасын жоғалтсаңыз, енгізген өзгерістеріңіз де жоғалады. Оқу деректерін қайта бастау үшін бұрынғы базаны сақтап қойып, жаңа PRAKTIKA_DB жолын қолданыңыз.

## Қысқа көрсету сценарийі

1. admin арқылы кіріп, басты бет пен практика тізімін көрсетіңіз.
2. Жаңа студент қосыңыз; іздеуден табыңыз.
3. Студентті ұйымға бөліңіз. Қате келісімшарт таңдап, тексеруді көрсетіңіз.
4. student арқылы кіріп, өз практикасына күнделік жазыңыз.
5. leader арқылы кіріп, күнделікті тексеріңіз және пікір қалдырыңыз.
6. Бағалау формуласын түсіндіріп, статистикадан CSV жүктеңіз.
7. Көмекшіден есеп құрылымын сұраңыз; кілтсіз режим екенін ашық айтыңыз.

## Осы нұсқаның шекарасы

Бұл оқу прототипі жергілікті компьютерге арналған. Файл жүктеу, жаңа аккаунт ашу, PDF генерациясы, хабарламалар және аудитті көру интерфейсі келесі кезеңге қалдырылған. Желілік өндірістік орналастыру үшін HTTPS, тұрақты сессиялар және толық пайдаланушы әкімшілігі керек. Жарияланған танысу беті тек оқу деректерін көрсетеді; толық мүмкіндіктер Python нұсқасында.
